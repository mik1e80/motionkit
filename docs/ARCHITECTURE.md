# 运动学模型、求解与验证

## 输入和交付终点

输入起点、终点、对称正上限 V / A / J。初末速度及加速度均为零，不接受任意状态。输出不可变 Profile：阶段、总时长和任意时间状态。没有文件格式兼容承诺或实机控制接口。

## 七段 S 曲线

先取正位移 D，最后将状态乘以方向。jerk 顺序为 `+J,0,-J,0,-J,0,+J`，时长为 `tj,ta,tj,tv,tj,ta,tj`；零时长阶段跳过。

达到速度上限时：若 `V > A²/J`，`tj=A/J`、`ta=V/A-tj`；否则 `tj=sqrt(V/J)`、`ta=0`。显式分支避免把理论零阶段算成微小正数。

达到 V 所需位移为 `Dcrit=V*(2*tj+ta)`。若 D 不小于 Dcrit，匀速时长 `tv=(D-Dcrit)/V`。

短行程没有匀速阶段。若不足以达到候选峰值加速度，`tj=cbrt(D/(2J))`、`ta=0`；否则保持 tj，求解 `D/Apeak=(tj+ta)*(2*tj+ta)` 的非负根。实现使用有理化根式以减小相消。

此构造专用于对称静止到静止问题。不将其推广为任意目标状态或多轴全局最优求解器。

## 分段积分

每个阶段保存起始状态、时刻、时长和常 jerk。局部时间 τ 的解析式为：

```
a(τ) = a0 + j*τ
v(τ) = v0 + a0*τ + j*τ²/2
p(τ) = p0 + v0*τ + a0*τ²/2 + j*τ³/6
```

先在相对坐标积分，再加世界起点。构造阶段检查有限性、端点上限、总时长和末端积分误差后才建立 Profile；最终时刻输出精确输入终点和零导数。这项输出约定不能代替上述内部末端误差检查。

S 曲线各阶段加速度不改变符号或单调到零，速度极值落在阶段端点；因此本构造的端点检查覆盖阶段内部峰值。此论证不适用于任意常 jerk 阶段列表，内部 assemble 不作为通用公开输入。

梯形速度是比较基线：正负常加速度夹匀速阶段，短行程变成三角速度。其加速度可跳变，不受有限 jerk 上限约束。

## 多轴同步

每轴先独立规划，公共时间 T 取各轴时长与用户最短时长的最大值。令 `r=Ti/T<=1`，查询局部时刻 `r*t`，导数分别乘 `r,r²,r³`。放慢不会增加运动学上限。静止轴始终保持原位置。

这只同步结束时刻，不同步各阶段，不保证笛卡尔直线或碰撞自由。不同轴沿各自独立路径移动。

## 精度和覆盖不能由成功返回代替

名义输入范围之外还有组合精度限制。非零位移要求世界坐标的保守舍入尺度 `max(abs(start),abs(target))*2^-52` 不大于总行程的 1e-6。阶段累计时刻形成的实际时间差与原计划阶段时长，相对偏差也不得超过 1e-6。失败时返回明确原因，不能仅用末端设置为 target 的输出掩盖中间轨迹的分辨率不足。

`bounds()` 对本库构造的曲线解析计算峰值，阶段内速度极值在端点；不是网格采样估计。梯形加速度跳变使 jerk 在交界没有有限上限，因此用 `JerkBound::Unbounded` 表达；不能把阶段内部 jerk=0 当成整体峰值。静止轨迹为 `Finite(0)`，S 曲线为有限分段 jerk 峰值。同步后按时间导数幂次缩放峰值。

## 独立验证和 AI 协作

解析示例用手算时长与终点；每段速度为二次函数，用 Simpson 规则独立积分，其结果与位移比较。中心差分核对公开位置、速度、加速度的导数。160 组不同位移、限值与方向检查单调性、有限性和运动上限。

发布脚本不依赖源码工作区的构建结果：重新打包并从解包内容构建独立消费模块，再解析实际导出的 CSV。

项目使用 AI 辅助设计、实现、测试与文档。参赛者需能够解释上述公式、数值范围、静止端点、jerk 跳变和同步方式，不能用测试数量代替对算法的理解。

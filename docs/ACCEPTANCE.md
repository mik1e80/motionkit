## 从已知失败案例补齐的证据

- 范围承诺与读取 / 检查覆盖混淆：将梯形的无限 jerk 与 S 曲线有限 jerk 放入公开类型，README、注册表文档和示例一致说明。
- 非有限数被静默接受：公开规划、同步、时间查询分别覆盖 NaN 及正负无穷，发布包消费测试复核失败路径。
- 归一化或端点输出掩盖误差：补充世界坐标分辨率和累计阶段时间分辨率限制，给出正常对照及可执行反例。
- 文档有案例但无法验证：`docs/FAILURE_CASES.md` 与 `cmd/boundary_demo` 对应，CI 和实际解包后的示例均需验证，意外成功将非零退出。
- 许可只留在仓库、包中遗漏：发布检查核对真正 ZIP 中的完整项目许可、第三方声明和本次新增案例文件。当前没有第三方样例或网页分发产物；未来新增时仍需单独核对相应条款。

交付边界：离线、对称、静止到静止的运动学库。未实现任意初末状态、路径转角前瞻、碰撞、动力学、硬实时或设备接口，不宣称完整运动控制器或通用时间最优轨迹求解器。

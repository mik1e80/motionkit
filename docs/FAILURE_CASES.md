# 可复现的失败与覆盖边界

这些是自建数值反例及接口语义案例，不是实机故障记录。运行 `moon run cmd/boundary_demo`，程序核对每个失败案例和正常对照，结果不符将非零退出；CI 同时运行 wasm 和 JS。

## 长匀速段不能吞掉短制动段

输入 `start=0,target=100,V=1e-6,A=1e6,J=1e6`。总时间约 1e8，而 jerk 阶段约 1e-6。旧实现只检查累计时间是否严格增加，仍会接受，但舍入后的短阶段时间偏差已过大。

修订后检查每段实际可表示时间差与计划时长，相对偏差超过 1e-6 返回精度错误。不能仅因为末端位置被设置成 target 就声称整个轨迹可准确采样。

## 大坐标、小行程

输入 `start=1e8,target=1e8+0.001,V=2,A=3,J=4`。参数分别位于名义范围内，但世界位置的分辨率相对于行程太粗。

修订后拒绝该组合，并提示平移原点。正常对照 `start=0,target=0.001` 被接受。若调用前两个位置已舍入成同一个 Double，输入中已无位移信息，零位移结果不代表原始实数意图被恢复。

## 有数值不等于符合全部上限

梯形速度轨迹内部采样的 jerk 为 0，但加速度在阶段交界跳变，整体 jerk 不受有限上限限制。旧接口需要使用者阅读文档才知道这一点，容易把成功生成误解为 Limits 三项均已满足。

现在 `Profile::bounds().jerk` 为显式 `Unbounded`；S 曲线和静止轨迹为 `Finite(value)`。同步曲线返回时间缩放后的逐轴解析峰值。它们不是只采样少数时刻得到的估算值。

## 非有限数必须失败

NaN 和正负无穷出现在位置、速度、加速度、jerk、查询时间或最短同步时长时，公开入口返回错误。验证文件 `precision_wbtest.mbt` 同时覆盖单轴和多轴，防止只修复某个入口。

## 仍未覆盖的能力

非零初末速度 / 加速度、在线重规划、路点转角、碰撞、动力学和实时硬件控制尚未实现。`synchronize` 只保证结束时间一致，不保证笛卡尔直线；无异常输出也不表示这些未实现能力通过验证。
